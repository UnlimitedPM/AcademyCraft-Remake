![title]
Terminal de datos

![brief]
El terminal de datos es tu caja de herramientas personal: contiene las aplicaciones que haya instalado el instalador de aplicaciones.

![content]
El terminal de datos trae dos aplicaciones: Ajustes y MisakaCloud. Además tiene otras tres: Árbol de habilidades, Reproductor multimedia y Transmisor de frecuencia. Estas aplicaciones extra se instalan con el instalador de aplicaciones.

La tecla ![key id="open_data_terminal"] abre o cierra el terminal de datos.

Esta es la presentación de cada aplicación.

__Árbol de habilidades__: tu nivel, la experiencia de tus habilidades y las que tienes disponibles.

__Transmisor de frecuencia__: ayuda a establecer las conexiones entre matrices, nodos, generadores, etc.

__Reproductor multimedia__: reproduce la música.

__Ajustes__: tus atajos y las demás opciones.

__MisakaCloud__: esto mismo que estás leyendo.
