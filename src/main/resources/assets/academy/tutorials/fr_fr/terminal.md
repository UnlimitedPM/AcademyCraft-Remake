![title]
Terminal de données

![brief]
Le terminal de données est votre boîte à outils personnelle : il contient les applications installées par l'installateur d'applications.

![content]
Le terminal de données a deux applications de départ : Réglages et MisakaCloud. Il en a trois autres : Arbre des compétences, Lecteur média et Émetteur de fréquence. Ces applications supplémentaires s'installent avec l'installateur d'applications.

La touche ![key id="open_data_terminal"] affiche ou referme le terminal de données.

Voici la présentation de chaque application.

__Arbre des compétences__ : votre niveau, l'expérience de vos compétences et celles qui vous sont accessibles.

__Émetteur de fréquence__ : il aide à établir les liaisons entre les matrices, les nœuds, les générateurs, etc.

__Lecteur média__ : il joue la musique.

__Réglages__ : vos raccourcis et les autres options.

__MisakaCloud__ : c'est ce que vous êtes en train de lire.
