![title]
Générateur de phase

![brief]
Le générateur de phase extrait l'énergie imag du liquide de phase imag.

![content]
Le liquide de phase imag contient peu d'énergie imag, que le générateur de phase libère. L'eau s'évapore pendant l'opération : il ne reste que l'énergie imag.

C'est rapide, mais le rendement est faible. À n'utiliser qu'au tout début.
