2. Statement of changes (GNU GPLv3, section 5a)
-----------------------------------------------

The files of this repository were CHANGED. Dated 2026.

    * The whole Java source was rewritten for Minecraft 1.20.1 and Forge 47: the original's
      classes are re-implemented, not mechanically translated — Minecraft's own API changed
      too much for that (materials, rendering, capabilities, data packs).
    * The original's assets are REUSED: textures, models, sounds, language files, tutorials
      and the interface layout documents. They are distributed here under the same GPLv3.
    * The original's numbers (costs, cooldowns, ranges, experience, damage) and behaviour are
      ported as they were, and are quoted in the comments of the classes they come from.
    * Things the port adds are marked as such in the code and in CHANGELOG.md.

Every file's history is public; `git log` is the record of what changed and when.
